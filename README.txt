# Prakash Jha — Personal Portfolio Website

This is a static website and can be hosted free on GitHub Pages.

## Files
- index.html
- style.css
- profile.jpg
- profile-working.jpg

## Free hosting
1. Create a GitHub account.
2. Create a **public** repository named `YOUR-USERNAME.github.io`.
3. Upload all four files.
4. Open Settings → Pages and select the repository's main branch.
5. Your website will be available at `https://YOUR-USERNAME.github.io/`.

No paid hosting is required.
